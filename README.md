# Карточка товара Teaboom.ru — «Ананасовый улун»

Тестовое задание (HTML/CSS-вёрстка) для интернет-магазина «Чайный Бум» (Teaboom.ru): верхняя часть карточки товара — изображение, категория, название, артикул, выбор фасовки, цена со старой ценой и скидкой, кнопка «В корзину» и короткое описание.

## Что реализовано

- Семантичная разметка HTML5: `main`, `nav` (хлебные крошки), `article`, `figure`, `fieldset/legend`, `section`.
- Выбор фасовки на нативных `radio`-кнопках: работает с клавиатуры (стрелки, Tab), виден фокус.
- При смене фасовки обновляются артикул, цена, старая цена, процент скидки и выбранное состояние (vanilla JS, данные в `data-*` атрибутах разметки).
- Кнопка «В корзину»: обычное состояние, `:hover`, `:active`, `:focus-visible`; по нажатию выводится статус (реальная корзина не подключается).
- Grid + Flexbox, mobile-first; проверено на 1440, 768 и 375 px без горизонтальной прокрутки.
- Стилистика Teaboom.ru: зелёный акцент, оранжевые метки скидки, шрифт Montserrat, светлый фон.
- Без Bootstrap и фреймворков.

## Структура

```
index.html            разметка карточки
css/style.css         скомпилированные стили (подключены к странице)
scss/
  style.scss          точка входа
  _variables.scss     цвета, шрифты, брейкпоинты
  _mixins.scss        медиа-запросы, фокус
  _base.scss          сброс и базовые стили
  _breadcrumbs.scss   хлебные крошки
  _product.scss       карточка, фасовки, цена, кнопка (БЭМ)
js/main.js            переключение фасовки
img/                  фото товара (с Teaboom.ru)
```

## Запуск

Достаточно открыть `index.html` в браузере. Либо локальный сервер:

```bash
npx serve .
```

## Пересборка SCSS

```bash
npx sass --no-source-map scss/style.scss css/style.css
# режим наблюдения:
npx sass --watch --no-source-map scss/style.scss css/style.css
```
